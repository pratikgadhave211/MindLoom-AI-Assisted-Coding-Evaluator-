# Local predictometer example

This example describes the existing Flaskr post-ownership challenge. The JSON and reference patch are author-side evaluation material, not files to copy into a user's workspace. This example is committed as development material and is not secret; real assessment guidance and reference fixes require private storage.

The prompt limit of 10 is an example for local development. It is not currently enforced and does not change the agent's separate per-turn tool limit.

The path and pattern entries are hints, not proof that a solution is correct or incorrect. Other valid fixes are possible. The reference patch is a candidate fix verified against the existing `tests/test_blog.py`; those tests do not prove all behavior is correct.
